# Contributing

## Branch Strategy

- `main` — producción. Solo merges desde `develop` tras revisión.
- `develop` — integración. **Toda contribución va aquí.**

## Commits

Usar [Conventional Commits](https://www.conventionalcommits.org/):

```
feat: nueva funcionalidad
fix: corrección de bug
chore: mantenimiento (deps, config)
refactor: cambio sin nueva funcionalidad ni fix
style: formato/estilo sin cambio lógico
docs: documentación
```
