Convenciones del Proyecto

Naming

  • Componentes: PascalCase EfectivoGlobal.tsx
  • Stores: camelCase navStore.ts
  • Archivos: PascalCase para componentes
  • Directorios: PascalCase para páginas Dashboard/

Exports

  • Named exports para todos los componentes
  • Sin default exports (excepto App.tsx)
  • Barrel exports en index.ts para grupos

Estado Global

  • Zustand para estado global (stores modulares)
  • React Context para temas transversales
  • Sin prop drilling

Estilos

  • Tailwind CSS v4 con tokens del DS
  • Nunca CSS manual
  • Tokens: var(--color-verde-100)

Iconos

  • HeroIcons (react-icons/hi2) en navegación
  • Lucide React en páginas internas
  • Reemplazo de FontAwesome → lucide-react

Stack

  • React 19 + Vite 8 + TypeScript 6
  • React Router v7 + Zustand 5
  • Chart.js 4 + Leaflet 1.9
  • @worksuiux-ctrl/my-design-system
